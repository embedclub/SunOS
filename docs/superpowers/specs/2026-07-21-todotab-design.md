# 桌面便利贴 TODO 程序 - 设计文档

## 概述

Windows 10+ 桌面便签式 TODO List应用(exe程序)，采用看板式单窗口置顶显示，现代磨砂风格UI。支持代办项的优先级管理，进度跟踪，完成标记，截止日期和定时提醒。

### 目标用户
个人用户，需要在日常工作中快速记录和跟踪代办事项。

### 核心价值

- 桌面置顶，随时可见，不遗漏代办
- 看板式管理，状态一目了然
- 轻量本地执行，无网络依赖

## 技术选型

| 决策项   | 选择| 理由 |
| 技术栈   | Python 3.10+ + PyQt5 | 开发效率高，UI丰富，PyInstaller打包exe |
| 数据存储 | 本地 JSON 文件 | 零依赖，简单可靠，易于备份 |
| 展示形式 | 单窗口看板式   | 一个主窗口显示所有Todo，窗口置顶贴桌面 |
| 提醒方式 | 系统托盘通知 + 应用内弹窗 | 双通道确保不漏掉提醒 |
| 界面风格 | 现代磨砂风格 | 半透明背景，圆角卡片，Fluent Design风格 |
| 架构方案 | MVC模块化 | 职责清晰，易维护和扩展 |
| 打包工具 | PyInstaller | 将Python应用打包为单个exe |

### 顶部框
| 标题 | DeskTop Todo | 深蓝色 |
| 最小化 | '-'图标表示 | 点击后将应用最小化 |
| 置顶切换 | 针状表示，选择红色| 默认置顶，鼠标点击后取消置顶 |
| 关闭 | 'x'图标表示 | 点击后应用退出 |

### 工具栏

| 组件 | 说明 |
|------|------|
| [新建待办] 按钮 | 点击弹出新建待办对话框 |
| 筛选下拉框 | 选项：全部、高优先级、中优先级、低优先级；按优先级过滤卡片 |
| 搜索框 | 实时搜索，按标题关键字匹配并高亮显示结果 |

### TODO 卡片（每一项）

卡片内容：

- **优先级色条**: 卡片顶部色条（红/橙/绿标识优先级）
- **标题**: TODO 内容文字
- **截止时间**: 显示剩余天数/小时，过期显示红色警告

### 新建代办对话框

点击顶部 [新建待办] 弹出模态对话框，包含：

- **标题** (必填): 文本输入框
- **任务详细描述** (可选): 多行文本区域
- **优先级**: 下拉框（高/中/低），默认中
- **进度条**: 可拖动的百分比滑块（0-100%）
- **截止时间** (可选): 日期时间选择器：提供勾选按钮，勾选后修改截止时间
- **提醒设置** (可选):
  - 提供勾选按钮，勾选后设置提醒时间
  - 启用提醒: 复选框
  - 提醒时间: 日期时间选择器（可添加多个时间点）
  - 重复提醒间隔: 下拉框（不重复/5分钟/15分钟/30分钟/1小时）
  - 周期性重复: 下拉框（不重复/每天/每周/每月）
- **备注** (可选): 多行文本区域
- **[确认] / [取消] 按钮**

## 数据结构 (JSON)

```json
{
  "version": 1,
  "todos": [
    {
      "id": "uuid",
      "title": "完成项目报告",
      "description": "详细描述内容...",
      "notes": "备注内容",
      "due_date": "2026-07-25T18:00:00",
      "priority": "high",
      "progress": 60,
      "stage": "in_progress",
      "completed": false,
      "created_at": "2026-07-21T09:00:00",
      "updated_at": "2026-07-21T14:30:00",
      "reminders": [
        {
          "id": "uuid",
          "time": "2026-07-21T15:00:00",
          "enabled": true
        }
      ],
      "reminder_snooze_interval": 15,
      "reminder_repeat": "none"
    }
  ]

```

### 字段说明

| 字段 | 类型 | 说明 |
|------|------|------|
| id | string | UUID 唯一标识 |
| title | string | 任务标题 |
| description | string | 任务详细描述 |
| notes | string | 备注 |
| due_date | datetime | 截止时间 |
| priority | enum | "high" / "medium" / "low" |
| progress | int | 0-100 百分比 |
| stage | enum | "todo" / "in_progress" / "completed" |
| completed | bool | 是否完成 |
| created_at | datetime | 创建时间 |
| updated_at | datetime | 最后更新时间 |
| reminders | array | 提醒时间点列表 |
| reminder_snooze_interval | int | 提醒沉默间隔（分钟），0 表示不重复 |
| reminder_repeat | enum | "none" / "daily" / "weekly" / "monthly" |

### 存储位置

`data/todo.json`（exe 所在目录下）

## 功能模块

### 1. 卡片编辑
- 卡片右上角用三个竖点做按钮，鼠标靠近后右击有三个选择——编辑、标记完成、删除
- 卡片标记完成，该卡片从代办或者进行中移动到完成列
- 卡片进度非0情况下，该卡片从代办移动至进行中

### 2. 提醒系统
- 后台定时器每秒检查一次
- 到达提醒时间 → 弹出提醒窗口 + 播放提示音 + 任务栏闪烁
- 提醒窗口：半透明弹窗显示任务标题
- 点击"已读"关闭提醒窗口
- 如有重复间隔（snooze），在间隔时间后再次提醒
- 如有周期性重复（daily/weekly/monthly），在下一周期重新创建提醒

### 3. 筛选与搜索
- 筛选：根据优先级过滤，仅显示匹配项
- 搜索：实时模糊搜索标题，匹配项高亮显示

### 4. 数据持久化
- 每次操作（增/删/改/拖拽）自动保存
- 程序启动时自动加载

## 提醒音效

使用 `QSound` 播放内置 `.wav` 文件，打包在 exe 资源中。

## 打包配置

使用 PyInstaller 打包为单文件便携 exe（免安装，直接运行）：
- 入口: `main.py`
- 图标: `app.ico`
- 资源文件: 提示音 `.wav` 文件（内嵌到 exe）
- 输出: `dist/DesktopTodo.exe`
- 运行后自动在 exe 同目录下创建 `data/todo.json`
